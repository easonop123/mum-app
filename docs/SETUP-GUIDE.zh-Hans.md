# 一点力 · 设置指南（给家人）

这个应用是给她自己用的，用不用由她决定。它不是医生，也不能判断她做运动是否安全。

## 1. 装到她的 iPhone 上

1. 用 **Safari** 打开 **https://easonop123.github.io/mum-app/**。也可以用 iPhone 相机扫二维码（[open-on-iphone-qr.png](open-on-iphone-qr.png)），再点出现的链接。
2. 点 **分享**（方框加向上的箭头）。
3. 往下滑，点 **添加到主屏幕**。
4. 如果看到 **作为网页 App 打开**，请确认已打开。
5. 点 **添加**。

不同 iOS 版本的按钮名称可能略有不同。不添加到主屏幕，网页也能用。

请在联网时先打开一次。之后，文字说明、计划、求助电话和她的记录都可以离线使用。视频始终需要联网。

## 2. 第一次使用：由她自己回答

- 她选择 English 或 简体中文。屏幕顶部的按钮随时可以切换。
- 确认在新西兰。求助电话是 111 和 Healthline 0800 611 116。
- 回答几个健康问题，一次一个。**“不确定”也是很好的回答。** 请不要替她回答。家人的看法不能代替医生的检查。
- 如果她选了紧急症状，应用会停下来，显示求助电话。这是设计好的。

## 3. 显示“计划在等医生的建议”是正常的

计划一开始就是暂停的。开始练习之前：

1. 打开 **设置 → 给医生看的摘要**。有英文版给医生看，中文版给她自己看。可以给医生看、打印或复制。不会自动发送。
2. 看诊时，问摘要里列出的问题。
3. 之后，由她在 **设置 → 医生的意见** 里记录医生说的话：有没有看过背部情况，以及每个动作是否“可以做”。
4. 如果医生或物理治疗师**改了**练习，应用不能自己改，需要有意识地修改练习内容。

## 4. 第一次练习前

**设置 → 居家准备检查：**

- 稳固的椅子靠墙
- 可以扶的固定台面
- 合脚防滑的鞋
- 地面留出空间
- 手机放在不用弯腰就能看到的地方

**不需要**哑铃。除非以后物理治疗师建议用重物，否则不用管那一页。

## 5. 日常使用

- 默认练习日是星期二和星期五。可以在设置里改，两天中间至少隔一天。
- 练习时，屏幕上一直有 **停止 / Stop** 按钮。
- 练习后的第二天，下次打开应用时会问她感觉怎么样。
- 只有她自己选择，才会往下一个阶段走。“保持这个量”永远都可以。

## 6. 提醒（可选）

应用不能发通知。**设置 → 提醒** 里有设置 iPhone“提醒事项”的步骤，也可以生成一个日历文件，加不加由她决定。

## 7. 备份

所有内容只保存在手机上。请隔一段时间用 **设置 → 我的数据 → 保存备份**，把文件放在私密的地方。

在 Safari 和主屏幕 App 之间切换，或者换新手机时，用 **恢复**。恢复后会请她重新回答健康问题。

## 求助

- 紧急情况：**111**
- 不确定有多紧急？Healthline 健康热线 **0800 611 116**（免费，24小时）
