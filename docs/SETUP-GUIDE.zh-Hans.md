# 一点力 · 设置指南（给家人）

## 1. 装到她的 iPhone 上

1. 用 **Safari** 打开 **https://easonop123.github.io/mum-app/**。也可以用 iPhone 相机扫二维码（[open-on-iphone-qr.png](open-on-iphone-qr.png)），再点出现的链接。
2. 点 **分享**（方框加向上的箭头）。
3. 往下滑，点 **添加到主屏幕**。
4. 如果看到 **作为网页 App 打开**，请确认已打开。
5. 点 **添加**。

不同 iOS 版本的按钮名称可能略有不同。不添加到主屏幕，网页也能用。

请在联网时先打开一次。之后，除了视频，其他都可以离线使用。

**如果她之前已经装过第一个版本：** 下次打开时应用会自动更新。如果看到“应用有新版本了”，点 **现在更新** 就可以。

## 2. 第一次打开

选 English 或 简体中文，点 **开始吧**，就可以了。屏幕顶部的按钮随时可以切换语言。

## 3. 练习

- 点 **开始今天的练习**。第一页有简单的准备提示（椅子靠墙、扶住厨房台面、穿好鞋、手机放在看得到的地方），还有可选的 2 分钟走路热身。
- 一次一个动作：想看就看示范视频，然后点 **做完了**、**少做了几次** 或 **跳过**。
- 屏幕上一直有 **停止 / Stop** 按钮。点了会保存已经做的部分，并显示 111 和 Healthline 电话。
- 默认练习日是星期二和星期五。可以在 **设置 → 练习日** 里改，两天中间至少隔一天。
- 在一个阶段完成两次完整练习后，应用会问她要不要多做一点。**保持这个量** 永远都可以。在 **练习计划** 页面也可以自己选阶段。

## 4. 提醒（可选）

应用不能发通知。**设置 → 提醒** 里有设置 iPhone“提醒事项”的步骤，也可以生成一个日历文件，加不加由她决定。

## 5. 备份

所有内容只保存在手机上。请隔一段时间用 **设置 → 我的数据 → 保存备份**，把文件放在私密的地方。

在 Safari 和主屏幕 App 之间切换，或者换新手机时，用 **恢复**。

## 求助

- 紧急情况：**111**
- 不确定有多紧急？Healthline 健康热线 **0800 611 116**（免费，24小时）
